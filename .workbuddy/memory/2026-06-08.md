## JLPT N1 備考サイト開発

### 完成内容
- 构建了日语 JLPT N1 备考网站（纯静态 HTML/CSS/JS）
- 三个模块：例句 (200)、聴解 (200)、読解 (30)
- 使用 edge-tts (ja-JP-NanamiNeural) 批量生成 200 个例句 MP3 音频
- 日式极简冷淡风 UI，侧边栏导航 + 内容区

### 技术选型
- 纯静态 HTML/CSS/JS，本地浏览器直接打开
- TTS: Microsoft Edge TTS (edge-tts Python 库)
- 听力朗读: Web Speech API (ja-JP)
- 音频: 200 个 MP3，约 9.8MB
- 数据: data.js 嵌入，约 393KB

### 项目结构
- index.html — UI 框架和交互逻辑
- data.js — 全量数据 (EXAMPLES, LISTENING, READINGS)
- audio/ — 200 个 MP3 文件 (0001.mp3 ~ 0200.mp3)
- generate_tts.py — TTS 批量生成脚本
